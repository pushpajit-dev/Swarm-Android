## ✨ Features

- **⚡ Client-Side Autonomous Agent Swarm:** Dissects and rebuilds live webpage DOM hierarchies from scratch in real-time using parallelized visual agents.
- **🎵 Real-Time Web Audio Synthesis:** Procedural micro-tone audio feedback as each DOM layer and node is placed by the agents.
- **🎨 Material 3 Frosted Glass Dual-Pill UI:** Floating search capsule and bottom control dock with 28dp smooth pill corners over a 100% fullscreen canvas.
- **🎥 720p HD Hardware Screen Recorder:** Built-in hardware GPU recording (`PixelCopy` + `MediaCodec` + mono audio muxing) with zero UI lag.
- **🌐 Universal Web Compatibility:** Supports modern SPAs, complex layouts, Google Search, and YouTube (`m.youtube.com`) with HTML5 fullscreen video support.
- **📱 Sketchware Pro & Native Ready:** Includes the ready-to-import `.swb` project archive and clean Java/Android source tree.

## 📥 Download & Installation

### Option 1: Direct APK Install
Download the compiled APK directly from the latest GitHub Release:
👉 **[Download SwarmMobile.apk](https://github.com/pushpajit-dev/Swarm-Android/releases/latest/download/SwarmMobile.apk)**

### Option 2: Sketchware Pro (.swb)
1. Download [`sketchware/Swarm_Mobile.swb`](sketchware/Swarm_Mobile.swb).
2. Open Sketchware Pro on your Android device.
3. Tap **Restore Project** and select `Swarm_Mobile.swb`.
4. Run/Compile instantly!
